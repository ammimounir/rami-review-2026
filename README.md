# رفيق رامي — برنامج مراجعة اختبارات الأسدس الأول 2026–2027

تطبيق ويب ثابت باللغة العربية لتخطيط مراجعات السنة الأولى ابتدائي وتتبع التقدم يومًا بعد يوم. يعتمد على HTML/CSS/JavaScript دون خادم أو قاعدة بيانات.

## الملفات
- `index.html`: مدخل التطبيق.
- `style.css`: التنسيقات المتجاوبة.
- `app.js`: الخطة والأنشطة والتقييم والتخزين المحلي.
- `sources/`: صور برنامجَي الاختبارات الأصليين للمراجعة والتوثيق.
- `.nojekyll`: يتيح نشر الملفات الثابتة كما هي عند تفعيل GitHub Pages.

## التشغيل محليًا
افتح `index.html` في المتصفح. وإذا كانت سياسات المتصفح تقيد التخزين عند فتح ملف محلي، شغله بخادم ويب محلي أو افتحه على استضافة HTTPS موثوقة.

## الخصوصية والبيانات
- بيانات إتمام الأنشطة والتقييم تحفظ في **التخزين المحلي للمتصفح** (localStorage) على **الجهاز نفسه** فقط.
- لا تتزامن البيانات بين الهاتف والحاسوب أو بين المتصفحات تلقائيًا، حتى مع فتح الموقع نفسه.
- تصدير النسخة الاحتياطية JSON من داخل التطبيق ثم الاحتفاظ بها في مكان آمن؛ لا ترفع ملفات النسخ الاحتياطية إلى GitHub.
- المشروع يتضمن صورًا لبرنامج الاختبارات؛ لا تفعّل نشرًا عامًا إذا كنت لا تريد إتاحة هذه المواد للجميع.

### هام: GitHub Pages والمستودعات الخاصة
وجود المستودع في وضع **Private** لا يجعل صفحة **GitHub Pages** نفسها خاصة. في الحسابات العادية تكون المواقع المنشورة عامة على الإنترنت عندما تسمح الخطة بالنشر من مستودعات خاصة. نشر موقع Pages خاص فعلاً مع التحكم في الوصول يتطلب مؤسسة على **GitHub Enterprise Cloud** وإعداد خاصية Pages access control.

**للحفاظ على الخصوصية الكاملة:** احتفظ بالمستودع خاصًا ولا تفعّل GitHub Pages؛ استخدم النسخة المحلية، أو انشر التطبيق على خدمة توفر تسجيل الدخول وإدارة الوصول قبل فتح الصفحة.

## إنشاء مستودع خاص
1. افتح https://github.com/new
2. سمِّ المستودع `rami-review-2026` واختر **Private**.
3. أنشئ المستودع **بدون README ابتدائي** (ملف README موجود في الحزمة).
4. ارفع الملفات الموجودة في **جذر هذه الحزمة** (مع الحفاظ على مجلد `sources/`).
5. اترك `Settings → Pages` غير مفعل حفاظًا على خصوصية الصفحة حتى تختار طريقة وصول آمنة.

## مرجعية المراجعة
الأنشطة تدريبية؛ يجب الرجوع إلى الكتاب ودفتر المدرسة لنص الحكاية، والمحفوظات، ومحتويات الدروس غير المبينة في جدول الاختبارات.
